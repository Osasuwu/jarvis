## redrobot — `SergazyNarynov/redrobot`

### 1. `Step.repeats` + разброс в отчёте дня — AFK

Поле `repeats: int = 1`, раннер прогоняет шаг n раз, `StepResult` копит наблюдения, `format_day_report` печатает разброс. `__post_init__` требует `repeats > 1` для шагов с числовым вердиктом; признак «числовой вердикт» объявляется **явным полем**, не выводится эвристикой (иначе AFK-вопрос 3 срабатывает).

Почему гейт, а не проза: сегодня «три повтора» живёт текстом ровно в одном шаге блока B, остальные шаги — `n=1` по умолчанию и молча.

Blocked by: —

### 2. Записанное предсказание + surprise rate — AFK

Пометка ожидаемого исхода на строке матрицы, валидация «ровно одна строка помечена, либо явный `unknown`», `format_day_report` печатает долю сюрпризов и долю `unknown`.

Почему гейт: без записанного предсказания сюрприз не детектируется и «мы так и думали» неотличимо от подтверждения.

Blocked by: **1** — не по смыслу, а по файлу: обе правки трогают `Step` и `format_day_report`; параллельная отправка в sandcastle гарантирует конфликт.

### 3. Реестр осей неопределённости `AXES` как данные — **HITL** (вопросы 2 и 3)

Оси как данные + объявление шагом «варьирую / фиксирую» + печать непокрытых мест на `--dry-run`. Механика тривиальна; **список осей — доменный вызов из истории err221** (J4, скорость, инструмент, направление, нагрузка). Свежая сессия по одному AC выберет оси наугад — ровно тот провал, ради которого всё затевается.

Метка: `unsafe-for-afk`.

Blocked by: —

### 4. Гейт покрытия в репетиции — AFK

К существующему гейту различимости гипотез в `scripts/rehearse_robot_day.py` добавить гейт покрытия: печатать пары осей, не покрытые ни одним экспериментом дня, и ячейки без негативного двойника; красить жёлтым.

Почему: репетиция сегодня проверяет «различают ли эксперименты засеянные гипотезы», но не «покрыли ли эксперименты оси, о которых мы не знаем» — это ровно дыра err221 (J4 × скорость).

Blocked by: **3** (без осей как данных гейту не над чем работать)
